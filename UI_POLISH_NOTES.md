# Crushly UI polish

This pass keeps the existing app behavior and data flow intact while refining the SwiftUI presentation.

## Updated

- Replaced the manually overlaid tab bar with a safe-area inset so lists, forms, and buttons are no longer covered.
- Added consistent bottom breathing room to scrollable sign-in, terms, profile, spaces, and connections screens.
- Grouped the long profile form into clear card sections and improved input-field contrast.
- Reworked the main visual hierarchy with oxblood headings, coral details, cream surfaces, and a warmer primary action gradient.
- Added polished page headings and subtitles to Spaces and Connections.
- Refined the tab bar's selected state, badges, surface, shadow, and home-indicator treatment.
- Updated the account list styling to match the retro campus mood board.
- Preserved Dynamic Type scaling, VoiceOver labels, minimum tap targets, and existing navigation behavior.

## Visual tokens

- Cream: `#F9EDE0`
- Orange: `#FF7A00`
- Coral: `#F76F61`
- Oxblood: `#7A1F1F`
- Blush: `#FFB6C7`
- Periwinkle remains available as a supporting color, but primary actions now use the warmer red palette.
