# Crushly Retro Campus UI

This build keeps the existing authentication, Supabase, Pulse, Signal, matching,
notification, safety and demo logic intact. The visual layer was updated to match
the supplied Crushly retro campus design board.

## Updated

- Global palette: cream, orange, coral, oxblood, blush and periwinkle
- Serif display hierarchy with rounded system UI type
- Periwinkle gradient primary actions and oxblood secondary actions
- Warm raised cards, softer outlines and branded shadows
- Retro decorative background and expressive ray motif
- Branded launch and USC sign-in experience
- Pulse Mode hero and navigation header
- Layered blush/coral radar treatment
- Light, celebratory Heart Sync reveal
- Updated floating tab bar and app accent color

## Run in Xcode

1. Open `Crushly.xcodeproj`.
2. Select an iPhone simulator.
3. If Xcode asks, choose your own Development Team under Signing & Capabilities.
4. Press Command-R.

The project targets iOS 26 and uses Swift Package Manager. The first build may take
longer while Xcode resolves Supabase and its dependencies.
